# Phase 10 통합 테스트 매트릭스

## 계층과 목적

| 계층 | 실제 구성 | 검증 목적 |
|---|---|---|
| Frontend | Nginx `localhost:3000` | health, `/api` 프록시, 동일 출처 세션 |
| Backend | Express `backend:8080` | 인증, CSRF, RBAC, 목적별 API, 오류 상태 |
| Database | PostgreSQL 16 | 트랜잭션, 수량 무결성, 감사 로그, 정리 |
| Browser | 실제 렌더링 | 로그인 상태, 메뉴 전환, 상세·감사 화면, 콘솔 오류 |

## 자동 시나리오

### IT-01 3계층 health·세션·오류 계약

`frontend /health` 200 → `backend /api/health` 200·DB up와 `x-request-id` → 익명 비품 API 401 및 공통 오류 계약 → MANAGER 로그인 → 대시보드 200.

### IT-02 Docker HTTP 업무 왕복

익명/세션 생성 → CSRF 누락 등록 403 → 정상 등록 201 → 상세 200 → 대여 201 → 가용 제외 미만 수정 409 → 활성 대여 비활성화 409 → 반납 204 → 수정 200 → MANAGER 감사 로그 403 → 비활성화 204 → 목록 제외 → ADMIN 감사 로그에서 생성·수정·비활성화와 request ID·IP 확인 → 테스트 데이터 정리.

### IT-03 기업 자산 승인 왕복

직원 요청 → 관리자 승인 → 자산 배정·상태·감사·outbox 원자 반영 → 테스트 데이터 정리.

### IT-04 구매요청 검증

필수값 누락 400 → 타 조직 403 → 정규화 저장·감사 → 테스트 데이터 정리.

### IT-05 부분 입고·검수 자산화

승인 구매요청 → 발주 → 2/3 부분 입고 → 검수 전 자산 0 → 초과 입고 409 → PASS 자산 2개 → 중복 검수 409 → 잔여 1개 입고 → FAIL 자산 0 → 전량 상태·연결 확인 → 테스트 데이터 정리.

### IT-06 비밀번호 재설정

단회 토큰 사용 → 재사용 거부 → 기존 세션 폐기 → 새 암호 로그인 → 테스트 데이터 정리.

### IT-07 PostgreSQL 서비스 왕복

등록 → 대여 → 수량 감소 → 축소 409 → 반납 → 수량 복원 → 수정 → 비활성화 → 감사 로그 5건 이상 → 001·002 migration 이력 확인 → 테스트 데이터 정리.

### IT-08 다차원 보고·감사 검색

USER 보고 403 → 관리자 필터 자산 생성 → 부서·위치·유형·상태·기간 집계 → 동일 필터 CSV → `REPORT_EXPORTED` 필터 감사 검색 → 테스트 자산·이력·감사·outbox 정리.
