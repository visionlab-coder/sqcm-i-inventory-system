# Phase 10 통합 테스트 매트릭스

## 계층과 목적

| 계층 | 실제 구성 | 검증 목적 |
|---|---|---|
| Frontend | Nginx `localhost:3000` | health, `/api` 프록시, 동일 출처 세션 |
| Backend | Express `backend:8080` | 인증, CSRF, RBAC, 목적별 API, 오류 상태 |
| Database | PostgreSQL 16 | 트랜잭션, 수량 무결성, 감사 로그, 정리 |
| Browser | 실제 렌더링 | 로그인 상태, 메뉴 전환, 상세·감사 화면, 콘솔 오류 |

## 자동 시나리오

### IT-01 3계층 health·세션

`frontend /health` 200 → `backend /api/health` 200·DB up → 익명 비품 API 401 → MANAGER 로그인 → 대시보드 200.

### IT-02 Docker HTTP 업무 왕복

익명/세션 생성 → CSRF 누락 등록 403 → 정상 등록 201 → 상세 200 → 대여 201 → 가용 제외 미만 수정 409 → 활성 대여 비활성화 409 → 반납 204 → 수정 200 → MANAGER 감사 로그 403 → 비활성화 204 → 목록 제외 → ADMIN 감사 로그에서 생성·수정·비활성화 확인 → 테스트 데이터 정리.

### IT-03 PostgreSQL 서비스 왕복

등록 → 대여 → 수량 감소 → 축소 409 → 반납 → 수량 복원 → 수정 → 비활성화 → 감사 로그 5건 이상 → 테스트 데이터 정리.

## 브라우저 시나리오

ADMIN 세션 → 비품 관리 → 상세·수정 화면 → 감사 로그 → 20행 렌더링 → 공식 로고 로드 → 오류 오버레이·콘솔 오류 0건.

## 성공 기준

- 통합 테스트 3/3, 전체 테스트 20/20
- 실패·취소·skip 0건
- frontend·backend·database 모두 healthy
- 각 테스트가 고유 코드를 사용하고 `finally`에서 대여·비품·감사 데이터를 정리
- 브라우저 의미 있는 본문, 상세·감사 화면, 공식 로고 정상
