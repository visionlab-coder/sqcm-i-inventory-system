# 기능 개발 체크리스트

| 기능 | 정상 기준 | 실패 기준 | 자동 검증 |
|---|---|---|---|
| 로그인 | 세션 회전 후 대시보드 | 잘못된 암호 401, 5회 계정 잠금, IP+계정 제한 429 | 단위+HTTP 통합 |
| CSRF | 동일 세션 토큰 승인 | 누락/불일치 403 | 단위 |
| 권한 | MANAGER 쓰기, ADMIN 감사 | USER 쓰기 403 | 미들웨어/HTTP |
| 비품 등록 | 유일 코드와 수량 저장 | 중복 코드 409, 음수 거부 | 단위+DB 통합 |
| 비품 상세 | 현재 수량·위치·대여이력 조회 | 미존재 비품 404 | HTTP+브라우저 |
| 비품 수정 | 가용 제외 수량을 보존하며 명칭·분류·위치·수량 변경 | 가용 제외 수량보다 총수량 축소 시 409 | DB 통합+브라우저 |
| 비품 비활성화 | 활성 대여가 없을 때 목록에서 제외·로그 생성 | 대여 중이면 409 | DB 통합 |
| 대여 | 재고 감소·로그 생성 | 재고 초과 409 | DB 통합 |
| 반납 | 재고 복원·로그 생성 | 중복 반납 409 | DB 통합 |
| 검색 | 코드/이름/카테고리 | 50건 제한 | 수동 인수 |
| health | DB 연결 시 200 | DB 장애 시 503 | HTTP 통합 |
| 요청 추적 | 응답·로그·감사에 같은 request ID | 잘못된 외부 ID는 새 UUID로 교체 | 단위+HTTP 통합 |
| migration | 미적용 SQL 1회 순차 적용 | 적용 파일 checksum 변경 시 시작 실패 | DB 통합 |
| FR-001 조직 계층 | 법인/본부/부서/팀과 비용센터를 같은 조직 부모 아래 생성 | 잘못된 유형·다른 조직 부모·팀 아래 하위 조직 4xx | 단위+HTTP+DB 통합 |
| FR-002 사용자 초대 | ADMIN 재인증 후 초대, 해시 저장, 단회 활성화와 로그인 | USER 403, 중복·만료·취소·재사용 4xx | 단위+HTTP+DB 통합 |
| FR-003 역할 범위 | 수락 시 역할과 ORGANIZATION/DEPARTMENT 범위 생성 | 부서 범위의 소속 누락·다른 조직 연결 4xx | 단위+HTTP+DB 통합 |
| FR-025 구매 요청 | 품목·수량·금액·비용센터·필요일·사유 정규화 저장 | 누락·범위·형식 오류 400, 다른 조직 403 | 단위+HTTP+브라우저 |
| FR-026 발주·부분 입고 | 승인 요청 1회 발주, 일부/전량 입고 상태 계산 | 미승인·중복 발주·누적수량 초과 409 | 단위+HTTP+DB 통합 |
| FR-027 검수 자산화 | PASS 수량만큼 AVAILABLE 자산·이력·감사·outbox 생성 | 검수 전 자산 0, FAIL 자산 0, 중복 검수 409 | HTTP+DB 통합 |
| FR-033 다차원 보고 | 부서·위치·유형·상태·기간별 건수·취득가와 동일 필터 CSV | 잘못된 상태·날짜·기간 400, USER 403 | 단위+HTTP+DB 통합 |
| FR-035 감사 검색 | 행위·대상·작업자·기간·변경 전후 값·요청 ID 검색 | 비관리자 403, 잘못된 기간 400 | 단위+HTTP+DB 통합 |
| FR-009/016 기준정보 생명주기 | ADMIN이 유형·모델·업체·위치를 생성·명칭 변경·활성/비활성화하고 기존 자산 참조를 보존 | USER 403, 중복 코드 409, 잘못된 모델 분류 409, 비활성 항목은 업무 선택에서 제외 | 단위+HTTP+DB+브라우저 |
| FR-009 상태·사유 정책 | ADMIN이 고정 상태 표시 정책과 사유·적용 상태·추가 설명 정책을 관리하고 수동 상태 변경에 강제 | USER 403, 임의 상태 400, 중복 사유·비활성·적용 불일치 409, 필수 설명 누락 400 | 단위+HTTP+DB+브라우저 |

완료 시 `npm run check:full`, Docker 상태, 브라우저 핵심 흐름, `git diff --check`, 비밀 패턴 검사를 수행한다. 통합 환경 누락은 skip이 아니라 실패다.
