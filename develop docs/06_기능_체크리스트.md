# 기능 개발 체크리스트

| 기능 | 정상 기준 | 실패 기준 | 자동 검증 |
|---|---|---|---|
| 로그인 | 세션 회전 후 대시보드 | 잘못된 암호 401, 5회 잠금 | HTTP 통합 |
| CSRF | 동일 세션 토큰 승인 | 누락/불일치 403 | 단위 |
| 권한 | MANAGER 쓰기, ADMIN 감사 | USER 쓰기 403 | 미들웨어/HTTP |
| 비품 등록 | 유일 코드와 수량 저장 | 중복 코드 409, 음수 거부 | 단위+DB 통합 |
| 대여 | 재고 감소·로그 생성 | 재고 초과 409 | DB 통합 |
| 반납 | 재고 복원·로그 생성 | 중복 반납 409 | DB 통합 |
| 검색 | 코드/이름/카테고리 | 50건 제한 | 수동 인수 |
| health | DB 연결 시 200 | DB 장애 시 503 | HTTP 통합 |

완료 시 `npm test`, Docker 통합 테스트, `git diff --check`, 비밀 패턴 검사를 수행한다.
