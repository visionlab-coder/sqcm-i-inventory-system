# 서원토건 공식 로고 적용 지침

## 공식 자산

- 원본: `src/public/assets/seowon-official-logo.png`
- 화면용 표시 자산: `src/public/assets/seowon-official-logo-display.png`
- 짙은 배경용 공식 반전 자산: `src/public/assets/seowon-official-logo-reversed.png`
- 공식 출처: `https://www.seowonenc.co.kr/ci.html`
- 공식 표기: `SEOWON` 및 `Since 1991`

컬러 PNG는 사용자가 제공한 원본을 수정 없이 보존한다. 표시용 컬러 PNG는 투명 캔버스 여백만 잘랐으며 로고 픽셀, 색상, 비율과 문구를 변경하지 않는다. 반전형은 서원토건 공식 홈페이지에서 배포·사용하는 `logo_w.png`를 그대로 보존한다.

## 사용 규칙

- 임시 도형, 자체 제작 심볼, 재작성한 워드마크를 사용하지 않는다.
- 가로세로 비율을 고정하고 찌그러뜨리거나 회전하지 않는다.
- 흰색·베이지·밝은 회색 배경에는 컬러형을 사용한다.
- 파랑·남색·사진 오버레이 등 짙은 배경에는 공식 반전형을 사용한다.
- CSS 필터나 수동 픽셀 편집으로 컬러형을 반전하지 않는다.
- 로고 주변에 충분한 여백을 두며 배경과의 명도 대비를 확보한다.
- 접근성 대체 텍스트는 `SEOWON Since 1991`로 통일한다.
- 프론트엔드 Docker 이미지는 같은 원본 자산을 복사해 사용한다.

## 적용 범위

- 공식 반전형: 독립 SPA 로그인·사이드바, 기존 EJS 로그인·사이드바, HTML 목업 사이드바, 콘셉트 갤러리 헤더·로그인 배경
- 컬러형: 콘셉트 갤러리의 밝은 대시보드·등록 툴바와 관리자 패널
