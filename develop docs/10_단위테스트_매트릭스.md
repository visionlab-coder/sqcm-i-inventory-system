# Phase 9 단위 테스트 매트릭스

## 목적

PostgreSQL 통합 테스트 전에 서비스 계층의 입력·권한 전제·트랜잭션 성공과 실패 분기를 빠르게 검증한다. DB 클라이언트는 호출 순서와 SQL·파라미터를 기록하는 제어 가능한 테스트 대역을 사용한다.

## 테스트 구성

| 영역 | 검증 내용 | 개수 |
|---|---|---:|
| 도메인 입력 | 양의 정수, 0 허용 정수, 안전한 반환 경로 | 4 |
| 보안 | CSRF 생성·일치·누락, 사용자 응답 정제 | 4 |
| 비품 등록 | 정규화·감사·커밋, 중복 코드 409·롤백 | 2 |
| 비품 수정 | 가용 제외 수량 보존·전후 감사, 축소 409·롤백 | 2 |
| 비품 비활성화 | 활성 대여 409·롤백, 정상 비활성화·감사·커밋 | 2 |
| 대여 | 가용 재고 초과 409·롤백 | 1 |
| 반납 | 중복 반납 409·롤백, 분실 시 재고 미복원·감사·커밋 | 2 |
| 설정 | 운영 세션 비밀·secure cookie·정수 범위 | 2 |
| 로그인 제한 | IP+이메일 제한·성공 시 초기화 | 2 |
| 관측 | request ID·감사 trace·구조화 로그 | 2 |
| 합계 | `npm run test:unit` | 23 |

## 성공·실패 기준

- 성공: 23/23 통과, 실패·취소·skip 0건
- 트랜잭션 성공: `COMMIT`, 감사 로그, 클라이언트 반환 확인
- 트랜잭션 실패: 업무 변경 SQL 미실행, `ROLLBACK`, 클라이언트 반환 확인
- 경계 오류: 예상 `DomainError`와 HTTP 상태 409 확인
- 회귀: Docker 통합 테스트 3/3과 전체 `npm run check:full` 26/26 통과

## 실행 명령

```powershell
npm run test:unit
$env:INTEGRATION_BASE_URL='http://localhost:3000'
$env:INTEGRATION_DATABASE_URL='postgres://seowon:change-me@localhost:55432/seowon_inventory'
npm run check:full
```
