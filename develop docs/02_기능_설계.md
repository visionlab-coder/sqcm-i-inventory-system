# 기능 설계

## 계층

Browser → Nginx SPA·`/api` 프록시 → Express Router → 인증/권한 미들웨어 → Service → PostgreSQL Repository 순서다. 쓰기 기능은 Service의 트랜잭션 안에서 도메인 검증, 데이터 변경, 감사 로그 생성을 함께 처리한다.

## 로그인

1. CSRF 토큰이 포함된 폼을 제출한다.
2. 이메일/IP 속도 제한과 계정 잠금을 확인한다.
3. 동일 비용 비교를 위해 미존재 계정도 더미 BCrypt 해시를 검증한다.
4. 성공 시 세션 ID를 재생성하고 사용자 ID·역할만 저장한다.
5. 실패/성공을 감사 로그에 남긴다.

## 비품

코드는 유일하며 총수량·가용수량·최소재고는 음수가 될 수 없다. 총수량을 대여 중 수량 미만으로 낮출 수 없다.

## 대여/반납

대여 시 대상 비품 행을 잠그고 가용수량을 확인한 후 `loans` 생성과 수량 감소를 원자적으로 수행한다. 반납 시 활성 대여 여부를 확인하고 수량을 복원한다.

## 권한

- USER: 대시보드, 비품 조회, 본인 대여 조회
- MANAGER: USER + 비품 등록/수정, 대여/반납
- ADMIN: MANAGER + 사용자/감사 로그

## FR-025 구매 요청

요청함 구매 폼은 품목·수량·예상금액·비용센터·필요일·사유를 입력한다. Router는 HTTP 매핑만 담당하고 Service의 `createRequest`가 `PURCHASE` 유형을 판별해 필수 payload를 정규화한다. 금액은 소수 둘째 자리 문자열로, 수량은 정수로 저장한다. 누락·형식·범위 오류는 400과 필드 오류로 반환하며 요청 생성과 감사 로그는 같은 트랜잭션에서 처리한다.
