# 웹 애플리케이션 데이터 흐름

## 읽기 왕복

사용자 요청 → 세션 쿠키 → 인증 미들웨어 → 권한 검사 → 검증된 query → 매개변수 SQL → PostgreSQL → ViewModel 변환 → EJS HTML → 브라우저.

## 쓰기 왕복

폼 입력 → CSRF 확인 → 스키마 검증 → 권한 검사 → DB transaction → 도메인 행 잠금 → 비즈니스 규칙 검사 → 변경 + 감사로그 → commit → 성공 flash → PRG redirect.

## 로그인 왕복

이메일/비밀번호 → CSRF/속도 제한 → 사용자 조회 → BCrypt 비교 → 실패 누적 또는 세션 재생성 → 세션 PostgreSQL 저장 → 권한별 대시보드.

## 개발·출시 흐름

Issue → feature branch → 구현 → 단위테스트 → 문서 갱신 → commit → PR → build → deploy → health → 핵심 기능 검사 → 로그 → 성공/rollback.

## 저장 위치 원칙

- 사용자 안내: `client docs`
- 기술·DB·운영: `develop docs`
- 에이전트 실행 지침·프롬프트: `agent docs`
- 실행 코드: `src`, 스키마: `db`, 검증: `test`
