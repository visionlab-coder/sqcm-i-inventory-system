# 인프라 설계

## 로컬/검토 환경

Docker Compose 네트워크 안에 `app`과 `postgres`를 둔다. PostgreSQL healthcheck 성공 후 앱을 시작하며, 앱은 `/health`에서 DB 연결 상태를 반환한다.

## 설정

모든 비밀은 `.env` 또는 배포 플랫폼 Secret으로 주입한다. `.env`는 Git에서 제외한다. 운영은 HTTPS 종단 뒤에서 `COOKIE_SECURE=true`, 충분히 긴 `SESSION_SECRET`, 제한된 DB 계정을 사용한다.

## 배포 흐름

build → 단위/통합 테스트 → 이미지 빌드 → DB 백업 → migration → 배포 → `/health` → 로그인/대여/반납 스모크 → 로그 확인 → 성공 또는 이전 이미지·DB 백업으로 롤백.

## 관측

구조화 로그에 request id, 경로, 상태코드, 지연시간을 남기되 인증정보는 제외한다. healthcheck와 DB 용량, 5xx, 로그인 실패율, 연체 건수를 모니터링한다.
