# 사용자 가이드

## 로그인

이메일과 비밀번호를 입력합니다. 5회 연속 실패하면 15분간 계정이 잠깁니다.

## 비품 관리

비품 목록에서 검색·상태 필터를 사용합니다. 담당자 이상은 `비품 등록`에서 코드, 이름, 카테고리, 총수량, 최소재고를 입력합니다.

## 대여·반납

`대여 처리`에서 사용자, 비품, 수량, 반납 예정일을 선택합니다. 반납 시 상태를 정상/손상/분실 중 선택하고 메모를 남깁니다.

## 관리자

감사 로그에서 로그인, 등록, 대여, 반납, 권한 변경 이력을 확인합니다. 비밀번호나 세션 값은 표시되지 않습니다.
