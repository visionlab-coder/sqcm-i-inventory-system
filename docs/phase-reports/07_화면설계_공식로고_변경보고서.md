# Phase 7 변경 보고서 — 서원토건 공식 로고 통일

## 목표

사용자가 제공한 `SEOWON Since 1991` 공식 로고를 모든 UI 산출물의 단일 브랜드 원본으로 사용한다.

## 적용 결과

- [x] 공식 PNG 원본을 무변형으로 보존
- [x] 투명 여백만 제외한 표시용 PNG 작성
- [x] SPA 로그인·사이드바 적용
- [x] EJS 로그인·사이드바 적용
- [x] HTML 목업 적용
- [x] 11개 페이지 콘셉트 아트 각각에 공식 로고 레이어 적용
- [x] 임시 `▰` 심볼 제거
- [x] 대체 텍스트 통일

## 결정 기록

생성형 재제작은 공식 자형과 색상을 바꿀 위험이 있어 사용하지 않았다. 원본 PNG를 단일 소스로 두고 코드 기반 표시창과 레이아웃만 조정했다.
