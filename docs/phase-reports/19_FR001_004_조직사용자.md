## 데이터 흐름

`관리자 비밀번호 재확인 → ADMIN·조직 범위 → 조직/초대 정규화 → PostgreSQL 저장 → 감사`

`초대 링크 → CSRF·비밀번호 정책 → 토큰 해시 조회·행 잠금 → 사용자+역할범위+수락시각+감사 COMMIT → 로그인`

원문 토큰은 개발 응답에서 한 번만 전달하고 접근 로그로 전송되지 않는 URL fragment에 넣으며 DB·감사 로그에는 저장하지 않는다. 운영 응답에서는 토큰을 반환하지 않고 외부 알림 발송기는 후속 Outbox 소비자로 분리한다.
