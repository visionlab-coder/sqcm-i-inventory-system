## 남은 위험과 후속 범위

- FR-009의 상태·사유 기준정보는 아직 구현되지 않았다.
- FR-013 파일 업로드는 저장소 제공자와 보존 정책 결정이 필요하다.
- 장기 실행한 로컬 테스트 DB에 만료 세션 80건이 관찰되었다. 이번 기능 범위에서 임의 삭제하지 않았으며 유지보수 Phase에서 정리 정책과 배치 작업을 검토한다.
