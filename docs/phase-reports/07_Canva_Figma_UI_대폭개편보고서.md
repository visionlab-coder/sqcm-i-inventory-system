# Phase 7 변경 보고서 — Canva·Figma 레퍼런스 기반 대폭 개편

## 목표

AI 생성형 관리자 화면의 반복적인 카드 구조를 제거하고, 공통 디자인 시스템 안에서 페이지별 업무 성격이 분명한 화면으로 변경한다.

## 적용

- 실제 로그인: 헤리티지 숫자와 편집형 타이포 중심 비대칭 구성
- 실제 대시보드: 동일 KPI 카드 대신 주 지표·위험 신호·보조 지표 계층화
- 비품 관리: 검색과 비교 중심 카탈로그
- 대여·반납: 단계형 인계 워크플로와 이동 원장
- 감사 로그: 모노스페이스 변경 원장
- 콘셉트 아트: 11개 정적 AI 이미지를 업무별 HTML/CSS 아키타입 11종으로 교체

## 체크리스트

- [x] 공식 SEOWON 로고 유지
- [x] 공통 브랜드 토큰 유지
- [x] 11개 페이지의 레이아웃 아키타입이 서로 다름
- [x] 획일적인 KPI 카드 반복 제거
- [x] 주 행동과 위험 상태의 색 역할 분리
- [x] 모바일 대응 포함

## 완료 기준

자동 테스트, Docker 통합 테스트, 실제 브라우저 로그인·화면 전환, 콘셉트 갤러리 11개 렌더링을 확인하면 완료한다.
