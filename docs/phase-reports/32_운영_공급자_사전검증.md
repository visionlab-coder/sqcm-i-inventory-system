# Phase 32 운영 공급자 사전검증 보고서

- 상태: 저장소 계약 완료 / 실제 공급자 입력 대기
- 구현: 운영 manifest, HTTPS·OIDC callback·RPO/RTO·Secret 참조 검증, 선택적 live probe
- 보안: 평문 Secret을 거부하고 참조 URI만 허용하며 검사 결과에도 값을 출력하지 않는다.
- fail-closed: 템플릿은 실제 배포를 승인하지 않고, HTTP·다른 호스트 callback·누락 공급자를 차단한다.
- 자동 증거: 운영 계약 검사 통과, 관련 단위 테스트 4건 포함 전체 단위 테스트 통과
- 외부 게이트: 실제 IdP·저장소·검사기·DNS/TLS·Secret Manager 입력 후 `--probe` 실행
