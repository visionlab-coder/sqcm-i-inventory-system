# Phase 9 보고서 — 단위 테스트

작성일: 2026-08-06

## 1. 목표

기존 입력·보안 유틸리티 중심의 단위 테스트를 비품 서비스의 트랜잭션과 도메인 실패 분기까지 확장한다. 실제 PostgreSQL 연결은 통합 테스트에 맡기고, 단위 테스트는 빠르고 결정적인 분기 검증을 담당한다.

## 2. 추가 범위

- 비품 등록: 입력 정규화, 감사 로그, 커밋, 중복 코드 409와 롤백
- 비품 수정: 가용 제외 수량 보존, 수정 전·후 감사, 총수량 축소 409
- 비품 비활성화: 활성 대여 차단, 정상 비활성화와 감사 로그
- 대여: 가용 재고 초과 시 생성 방지와 롤백
- 반납: 중복 반납 차단, 분실 반납 시 재고 미복원
- 공통: 모든 경로에서 DB 클라이언트 반환 확인

## 4. 개선 효과

DB 장애가 아닌 도메인 규칙 실패를 빠르게 재현할 수 있고, 성공 시 커밋·감사 로그와 실패 시 롤백·변경 SQL 미실행을 독립적으로 증명할 수 있다. 분실 반납처럼 수량 복원이 없어야 하는 예외도 회귀 테스트로 고정했다.
