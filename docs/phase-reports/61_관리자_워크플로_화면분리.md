# Phase 61 — 관리자 정보구조·구매 워크플로 분리 보고서

## 완료 범위

- 관리자 화면을 조직·초대 / 승인 정책 / 기준정보 / 사용자·이벤트 탭으로 분리했다.
- 탭 외 섹션은 `hidden` 처리해 1440px 화면의 장문 누적과 우측 밀림을 줄였다.
- 요청함을 요청 작성 / 승인 큐 / 발주·입고·검수 단계 탭으로 분리했다.
- 승인·반려 사유 입력 필드를 추가하고 2자 이상 입력을 클라이언트에서 요구한다.
- 기존 서버 `transitionRequest`가 전달 사유를 승인 이력·감사 필드에 저장하도록 연결했다.
