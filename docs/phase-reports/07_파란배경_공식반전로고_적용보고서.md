# Phase 7 화면설계 보완 보고서 — 공식 반전 로고

작성일: 2026-08-06
대상: 서원토건 비품관리 시스템

## 1. 변경 목적

기존 컬러 로고의 파란 워드마크가 남색 배경에 묻히는 문제를 해결한다. 서원토건 공식 CI의 색상 활용 기준에 따라 짙은 배경에는 공식 반전형을 사용하고 밝은 배경에는 컬러형을 유지한다.

## 2. 공식 근거와 자산

- CI 페이지: `https://www.seowonenc.co.kr/ci.html`
- 공식 반전 자산: 서원토건 홈페이지의 `/assets/images/main/logo_w.png`
- 프로젝트 자산: `src/public/assets/seowon-official-logo-reversed.png`
- 검증 크기: 153×47 px, PNG 6,848 bytes

자산을 생성형 이미지로 다시 만들거나 CSS 필터로 변환하지 않고 공식 파일을 그대로 사용했다.

## 3. 적용 범위

- 독립 SPA: 로그인 비주얼, 남색 사이드바
- 기존 EJS: 로그인 비주얼, 남색 사이드바
- HTML mock: 남색 사이드바
- 컨셉 갤러리: 남색 헤더와 로그인 블루 패널

대시보드·등록 툴바·관리자 패널처럼 밝은 배경인 영역은 기존 컬러형을 유지했다.
