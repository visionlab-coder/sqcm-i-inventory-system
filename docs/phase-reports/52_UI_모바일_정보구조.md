# Phase 52 — 모바일 셸·관리자 정보구조·테이블 UX

## 구현

- 모바일 사이드바를 드로어로 전환하고 `aria-expanded`, Escape, 백드롭 닫기를 지원한다.
- 레거시 `items`·`loans` 메뉴를 숨기고 정식 자산 원장 중심으로 이동하게 했다.
- 이동 시 hash view 상태를 기록하고 스크롤을 상단으로 초기화한다.
- 자산 API 페이지·크기 파라미터를 UI에 연결하고 이전/다음 페이지를 제공한다.
- 테이블 수평 스크롤, 페이지 상태, 제품 포지션 콜아웃을 추가했다.
- Cost Command Center 진입 메뉴를 관리자·매니저에게 동적으로 노출한다.

## 검증

- `npm.cmd run ui:contract`: 8개 계약 통과
- 375×812 브라우저: 드로어 닫힘 상태에서 본문 overflow 없음, 토글 `false→true`, transform `offscreen→0`, Escape로 복원
- 1440×900 브라우저: body/main 수평 overflow 없음, hash view 유지
