# Phase 5 보고서 — 인프라 설계

- `frontend`: Nginx SPA·API 리버스 프록시, 호스트 3000 공개
- `backend`: Express API·인증·업무 규칙, 내부 8080
- `database`: PostgreSQL 16·영속 볼륨, 내부 5432
- 기동 의존성: database healthy → backend healthy → frontend
- 환경변수 비밀 주입, 운영 HTTPS 쿠키, 최소 공개 포트 원칙 적용
- 배포 흐름: build → test → deploy → 세 서비스 health → smoke → log → 성공/rollback
- 결과: Docker Compose 3계층 인프라 설계 및 구현 완료
