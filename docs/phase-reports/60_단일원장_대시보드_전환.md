# Phase 60 — 단일 원장 대시보드 전환 보고서

## 완료 범위

- 기업 `assets` 원장만 읽는 `/api/enterprise/dashboard` read model을 추가했다.
- 조직·부서 범위와 일반 사용자 본인 요청 범위를 서버에서 적용했다.
- 대시보드를 자산번호·위치·부서·상태 기반 화면으로 전환했다.
- 신규 자산 버튼은 `asset-register`로 연결하고 구형 `items/loans` 화면은 canonical 화면 alias로 바꿨다.
- 프런트엔드에서 `/api/dashboard`, `/api/items`, `/api/loans` 호출을 제거했다.
- UI contract에 canonical dashboard 및 레거시 API 호출 0건 검사를 추가했다.
