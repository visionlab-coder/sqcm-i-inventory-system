# Phase 8 보고서 — 기능 개발

작성일: 2026-08-06

## 1. 범위 결정

요구사항 `INV-01 비품 CRUD·검색`과 기존 코드를 대조한 결과 등록·검색은 구현되어 있었지만 상세 조회·수정·비활성화가 누락되어 있었다. 이번 Phase에서는 이 세 기능과 기능별 테스트를 구현했다.

## 2. 구현 내용

- 비품 상세 API와 화면: 현재 수량, 대여 중 수량, 위치, 최소재고, 상태, 최근 대여 이력
- 비품 수정: 명칭, 카테고리, 위치, 총수량, 최소재고
- 수량 무결성: `가용 제외 수량 = 총수량 - 가용수량`을 보존하고 그보다 작은 총수량 변경은 409로 거부
- 비품 비활성화: 활성 대여가 없을 때만 `INACTIVE`로 전환
- 감사 로그: `ITEM_UPDATED`, `ITEM_DEACTIVATED`와 수정 전·후 값 기록
- 등록 화면 위치 필드 추가
- 권한: MANAGER·ADMIN만 수정·비활성화, 조회는 로그인 사용자 허용

## 3. API

| 메서드 | 경로 | 권한 | 결과 |
|---|---|---|---|
| GET | `/api/items/:id` | 로그인 사용자 | 상세·최근 대여 이력 |
| PATCH | `/api/items/:id` | MANAGER, ADMIN | 관리정보 수정 |
| DELETE | `/api/items/:id` | MANAGER, ADMIN | 논리 비활성화 |
