# Phase 27 FR-024 반납 사진 증빙 보고서

상태: 완료

## 구현 결과

- RETURN 초안에 반납 상태, 부속품, 메모와 JPEG/PNG 사진을 연결했다.
- 요청자는 현재 활성 배정된 자산만 반납할 수 있고 다른 사용자의 초안에는 업로드할 수 없다.
- MIME뿐 아니라 파일 시그니처를 검증하며 PDF·위조 이미지·5 MiB 초과 파일을 거부한다.
- 제출과 최종 승인 시 활성 사진을 재검증한다.
- 최종 승인 트랜잭션에서 배정 종료, 반납 원장, 자산 상태, 승인 이력, 감사, Outbox를 함께 반영한다.
- 화면은 RETURN 선택 시에만 반납 필드를 노출하고 사진을 필수화한다.

## 브라우저 검증 범위

로그인 화면과 로컬 앱 응답은 브라우저에서 확인했다. 현재 자동화 브라우저에는 보안상 자격증명을 전달하는 인증 기능이 없어 로그인 후 파일 선택 UI 자동화는 수행하지 않았다. 대신 실제 Docker HTTP 세션, CSRF, 바이너리 업로드, PostgreSQL 결과를 포함한 통합 테스트로 해당 흐름을 검증했다.

## 남은 운영 결정

운영 객체 저장소와 악성코드 검사 공급자는 Phase 28에서 어댑터 계약·설정 검증·mock 통합·fail-closed 정책으로 준비한다. 실제 공급자 계정과 비밀은 저장소에 만들거나 기록하지 않는다.
