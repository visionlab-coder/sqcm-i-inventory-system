## 실패 개선 기록

1. test overlay 없이 재빌드해 DB 호스트 포트가 닫힌 상태에서 통합 테스트가 `ECONNREFUSED`로 실패했다. 운영 DB 비공개 원칙은 유지하고 `compose.test.yaml`에서만 테스트 포트를 열어 16/16을 재검증했다.
2. 이전 실패가 남긴 미참조 테스트 승인 정책 1건이 기본 승인 테스트에 영향을 줬다. ID·이름·참조 0건을 확인해 해당 테스트 데이터만 정리했다.
3. OIDC migration 이후 유지보수·복구 필수 목록이 30개에 머문 누락을 발견해 31개로 수정했다.
4. 이전 시점 백업은 최종 테스트가 추가한 감사 로그와 건수가 달라 비교가 실패했다. 최종 시점 백업을 새로 생성해 31개 테이블·13개 migration·주요 건수 일치를 확인했고 모든 임시 DB를 제거했다.
5. API 공통 미들웨어가 health 요청에도 CSRF 토큰을 만들면서 익명 세션이 누적됐다. health/readiness를 세션 미들웨어 앞으로 이동하고 전후 건수 불변 테스트를 추가했다. 확인된 실패 테스트 업무 행·고아 PNG와 인증/익명 세션을 범위를 좁혀 정리한 뒤 업무 테스트 행·파일·인증 세션·임시 DB 0건을 확인했다.

## 브라우저 한계

자동화 브라우저에 보안 자격증명 주입 기능이 없어 이번 최종 게이트에서 로그인 후 업무 화면을 다시 조작하지 않았다. 로그인 이후 흐름은 실제 Docker HTTP 세션·CSRF·역할·부서 범위·파일 업로드·PostgreSQL 통합 테스트 16개와 과거 브라우저 인수 증거로 검증했다.
