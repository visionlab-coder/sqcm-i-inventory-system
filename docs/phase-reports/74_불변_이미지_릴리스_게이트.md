# Phase 74 불변 이미지 릴리스 게이트

## 결과 / 상태

로컬 릴리스 계약은 **PASS**다. GitHub PR·main 병합·GHCR 발행 결과는 이 보고서의 후속 검증에서 갱신한다. 실제 production 배포는 운영 대상과 Secret이 없으므로 **NO-GO**를 유지한다.

## 변경 범위

- GitHub Actions 참조를 공식 commit SHA로 고정했다.
- main의 정확한 Git SHA로 frontend/backend 이미지를 GHCR에 발행하는 workflow를 추가했다.
- production 이미지는 `sha-`와 40자리 소문자 Git SHA, 공식 GHCR 경로, 서로 다른 두 저장소를 강제한다.
- 외부 배포는 서버 build를 금지하고 두 앱 이미지를 pull한 뒤 3서비스를 기동한다.
- database는 PostgreSQL 16 이미지와 운영 volume을 그대로 사용하며 앱 이미지 발행 대상이 아니다.

첫 main 발행은 성공했으나 Docker Actions의 Node.js 20 호환 경고가 확인되었다. 공식 최신 릴리스의 정확한 commit SHA로 후속 갱신하고 다시 발행해 경고 없는 실행을 검증한다.
