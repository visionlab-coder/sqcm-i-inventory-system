## 현재 사용 범위·남은 입력

등록된 직원은 `https://inventory.safe-link.co.kr/`에서 사용할 수 있다. 현재 활성 회사 계정은 **13개**, 초기 변경 대상 **10개**, 기존 개인 비밀번호 유지 **3개**다. 초기 변경 전 업무 API는 차단하며 신규 직원은 기존 조직·부서 권한의 USER다. 회사 도메인만 입력하는 자동 가입은 활성화하지 않았다. 약90명은 사용자 예상 인원으로 전체 등록을 검증한 수가 아니다. 다음 입력은 남은 직원의 회사 이메일 명단 위치다. 개인정보 명부는 Git에 포함하지 않는다.

첫 합성 시험은 호스트 의존성 경로에서 backend 시작 실패 후 동일 운영 SHA 이미지로 전환해 PASS했다. 첫 갱신 시도는 명부 불일치를 감지해 ROLLBACK했고, 실제 미등록2건을 추가한 뒤 PASS했다.
