# Phase 25 FR-007 부서 데이터 범위 보고서

상태: 완료

## 구현

- `ALL`, `ORGANIZATION`, `DEPARTMENT`, `SELF` 역할 범위를 세션 사용자와 연결했다.
- `DEPARTMENT`는 PostgreSQL 재귀 CTE로 기준 부서와 활성 하위 부서 ID를 계산한다.
- 자산 목록·상세·생성·상태 변경, 요청 목록·생성·검토, 보고서·CSV에 동일 범위를 적용했다.
- 파일 업로드·다운로드·비활성, 수리 등록·변경, 재물조사 생성·조회·항목 점검·확정 우회 경로에도 범위를 적용했다.
- 관리자 사용자 범위 변경은 사용자, `user_role_scopes`, 감사 로그를 한 트랜잭션에서 처리한다.
- 기존 계정은 migration 010에서 ADMIN=ALL, MANAGER=ORGANIZATION, USER=DEPARTMENT로 명시적으로 backfill한다.

## 데이터 흐름

Browser → Endpoint 인증/CSRF → Scope Service 역할·부서 재귀 조회 → Service 권한/범위 검증 → Repository 매개변수 SQL `ANY(bigint[])` → PostgreSQL → 안전한 응답 → Browser.
