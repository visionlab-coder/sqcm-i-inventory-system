# Phase 18 FR-033/035 다차원 보고·감사 검색 보고서

상태: 구현 완료 — 자동 브라우저 런타임 외부 장애는 Issue #3으로 분리

## 목표

부서·위치·유형·상태·취득기간별 자산 보고서를 제공하고 같은 조건의 CSV 다운로드를 감사한다. 감사 담당자는 핵심 행위와 metadata의 변경 전·후 값, 요청 ID를 실제 UI에서 검색한다.

- API: `/reports/assets`, 필터형 `/reports/assets.csv`, 필터형 `/api/audit`
- UI: 보고 조건·KPI·4개 차원표, 감사 검색 폼·원장
- 화면설계: 기존 보고서 컨셉 HTML을 필터·다운로드 감사 흐름으로 보완

## 데이터 흐름

`보고 필터 → RBAC·조직 → 공통 정규화 → PostgreSQL 차원 집계 → SPA/CSV`

`CSV → REPORT_EXPORTED(필터·행 수·요청 추적)`

`감사 검색 → ADMIN → action/entity/actor/date/metadata/request ID → 최대 200건`

## 성공·실패 기준

- 성공: 필터 결과와 CSV 대상이 같고 다운로드 감사 검색이 가능하다.
- 실패: USER 보고 접근, 잘못된 상태·날짜·역전 기간, 비관리자 감사 접근은 4xx다.
- 개인정보: 비밀번호·세션·토큰은 검색 대상 SQL과 UI에 포함하지 않는다.
