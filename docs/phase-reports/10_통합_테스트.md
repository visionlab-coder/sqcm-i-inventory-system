# Phase 10 보고서 — 통합 테스트

작성일: 2026-08-06

## 1. 목표

프론트엔드 Nginx, Express API, PostgreSQL, 실제 브라우저가 연결된 상태에서 인증·권한·재고·감사 흐름을 검증한다. 서비스 함수만 직접 호출하는 기존 DB 통합 테스트에 실제 HTTP 경계와 브라우저 렌더링을 추가한다.

## 2. 추가 시나리오

- 익명 보호 API 401
- MANAGER·ADMIN 로그인과 세션 재발급
- CSRF 누락 쓰기 요청 403
- 비품 등록·상세·수정·논리 비활성화
- 대여 중 총수량 축소와 비활성화 409
- 대여·반납 수량 왕복
- MANAGER 감사 로그 접근 403, ADMIN 접근 200
- 감사 로그의 `ITEM_CREATED`, `ITEM_UPDATED`, `ITEM_DEACTIVATED` 확인
- 비활성화 비품의 운영 목록 제외
- `finally`를 통한 테스트 데이터 정리

## 5. 데이터 격리

테스트별 고유 코드 `HT-*`, `TS-*`를 사용한다. 생성된 감사 로그, 대여, 비품은 성공·실패 여부와 관계없이 `finally`에서 역참조 순서로 제거해 재실행 가능성을 유지한다.
