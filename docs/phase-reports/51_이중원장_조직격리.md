# Phase 51 — 이중 원장 제거 및 조직 데이터 격리

## 목표

기업 자산의 기준 원장을 `assets`로 고정하고, 기존 `items`·`loans` 호환 API가 조직을 넘나들지 못하도록 한다.

## 구현

- `016_canonical_ledger_org_isolation.sql` 추가
  - `items`, `loans`, `audit_logs`에 `organization_id`와 인덱스 추가
  - 기존 행 조직 귀속 백필 및 FK/NOT NULL 적용
  - 감사 로그 INSERT 시 행위자 조직을 자동 귀속하는 trigger 추가
  - `users.is_system_admin` 추가
- ADMIN의 조직 전환은 `is_system_admin=true`일 때만 허용한다. 일반 ADMIN은 자기 조직 범위다.
- 레거시 대시보드·품목·대여·감사 조회에 조직 조건을 적용했다.
- `assets`를 정식 물리 자산 원장, `items`·`loans`를 호환·이력 계층으로 문서화했다.

## 검증

- `npm.cmd run check`: 구문 76개, 단위 92/92 통과
- Docker migration 001~019 적용 및 backend healthy
- 통합 테스트 17/17 통과
- 타 조직 접근은 403, 감사 로그 조직 인덱스·자동 귀속 확인

## 남은 위험

레거시 API 자체를 즉시 삭제하지 않고 호환 계층으로 유지했다. 신규 화면·Cost·AI는 `assets` 원장만 사용하며, 레거시 API 완전 폐기는 별도 deprecation 공지와 데이터 이관 승인 후 수행한다.
