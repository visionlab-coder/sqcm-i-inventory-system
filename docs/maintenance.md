# 유지보수 계획

## 주기

- 매일: health, 5xx, 로그인 실패 급증, 연체 건수
- 매주: DB 용량, 느린 쿼리, 감사 로그 샘플
- 매월: 의존성·이미지 취약점, 계정/권한 검토, 백업 복구 연습
- 분기: 재고 실사와 시스템 수량 대조, 보존기간 만료 로그 정리

## 장애 처리

감지 → 영향 범위 제한 → 증거 보존 → 최근 변경/DB/인프라 분류 → 복구 → 재검증 → 사후 기록 순서다. 데이터 삭제가 필요하면 정확한 대상과 백업을 확인하고 별도 승인을 받는다.
