# 전체 메뉴 PC·모바일 배치 점검 계약

1. 목적: 회사 직원이 모든 메뉴에서 여백·문구·입력·버튼을 잘림 없이 읽고 사용할 수 있게 한다.
2. 범위: 현재 주 메뉴14개, 1440px PC·390px 모바일과 확인된 중간 breakpoint; 기존 브랜드 유지. 업무 규칙·계정·DB·권한·터널은 제외한다.
3. 방식: 현재 운영 화면 읽기 전용 관찰 → 재현된 CSS 원인 최소 수정 → 관련 회귀·CI → frontend만 반영 → 같은 화면 재검증. execution_mode=single, Laya=RULE; 실행 모델 설정은 inherited/unknown이며 별도 모델 위임은 없다.
4. 정본: 사용자 요구, 프로젝트 AGENTS/CLAUDE, 실제 frontend와 현재 운영 브라우저. 기존 사용자 dirty4개를 보존한다. 기준 HEAD552010ee67a08eeda33eaad8fbee4c72ba3a55de.
5. 권한: 화면·코드 점검, UI 수정·검증·기존 작업 브랜치 체크포인트 및 같은 Inventory frontend 반영. 실제 업무 제출·데이터 생성·권한·Secret 변경은 하지 않는다.
6. 성공/실패: 메뉴별 PC/모바일 점검 근거와 재현 결함 수정; 문서 가로 넘침0, 입력·버튼 잘림0, 의도된 표 스크롤은 별도 기록. API·권한 오류는 UI PASS로 숨기지 않는다. 같은 실패3회 중단.
7. 검증: DOM geometry·스크린샷, UI 계약·구문·단위, 동일 SHA CI, 공개 smoke·3서비스 health·backend/DB 컨테이너 불변·보호 터널 보존. 빈 화면 점검은 실데이터·입력 완료 UAT와 구분한다.
8. 산출물: 최소 CSS/캐시 변경, 화면별 체크리스트·JSON 증거·조작 스킬 연결·현재 상태 갱신. Secret·계정명부·불필요한 개인정보는 제외한다.
