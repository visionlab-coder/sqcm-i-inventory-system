# Agent.md — 실행 지침

## 목표

서원토건 구성원이 비품의 현재 위치와 책임자를 즉시 확인하고, 대여·반납 누락과 재고 부족을 줄이는 시스템을 만든다.

## 작업 순서

방향준비 → 설계 → 구현·검증 → 출시·운영 순서를 따른다. 변경은 Issue → branch → 구현 → 단위테스트 → 문서 갱신 → commit → PR 흐름을 사용한다.

## 기술 맥락

- Node.js 24, Express, EJS, PostgreSQL 16
- 세션 인증, RBAC, CSRF, BCrypt, Helmet
- Docker Compose로 앱과 DB 실행
- `src` 애플리케이션, `db` 마이그레이션, `test` 테스트, `docs` 보고서

## 통제와 금지

- 비밀번호·세션 원문·DB 비밀을 코드나 로그에 남기지 않는다.
- 권한은 화면 숨김이 아니라 서버 라우트에서 검사한다.
- 재고 변경과 대여·반납은 DB 트랜잭션으로 처리한다.
- 임의 데이터 삭제, 운영 배포, 외부 공유는 승인 범위 안에서만 수행한다.

## 완료 정의

요구사항 추적표가 코드·테스트와 연결되고, 단위·통합 테스트가 통과하며, Docker 상태 확인과 핵심 스모크 테스트 절차가 문서화된 상태다.

## 메모리

다음 작업에 남길 것: 결정 기록, 마이그레이션, 테스트 결과, 미완료 배포 항목. 없앨 것: 임시 토큰, 테스트 세션, 개인 식별 데이터가 포함된 로그.
