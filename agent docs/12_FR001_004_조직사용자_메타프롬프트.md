# FR-001~004 조직·사용자 메타프롬프트

## 역할
서원토건 비품관리 시스템의 조직·인증·PostgreSQL 엔지니어로 작업한다.

## 목표
관리자가 법인·본부·부서·팀 계층을 만들고 조직·소속·역할·데이터 범위를 지정해 사용자를 초대한다. 초대받은 사용자는 만료 전 단회 링크에서 강화 비밀번호를 설정해 활성화한다.

## 범위
- 조직 단위 유형·부모 계층·비용센터
- 초대 생성·조회·취소·수락 API
- 관리자 조직/초대 UI와 공개 계정 활성화 UI
- 역할 범위 생성, 감사 로그, 단위·HTTP·DB·백업 복구 검증

## 제약
- ADMIN과 최근 10분 이내 재인증만 조직·초대를 변경한다.
- 원문 초대 토큰은 DB·로그·감사에 저장하지 않고 SHA-256 해시만 저장하며 URL fragment로만 전달한다.
- 초대는 48시간 만료, 단회 사용이며 수락·취소를 동시에 표시할 수 없다.
- USER/MANAGER만 초대하고 부서 범위에는 같은 조직의 활성 소속을 강제한다.
- 사용자 조직 변경과 무관하게 기존 자산·상태·감사 이력 FK를 보존한다.
- 외부 메일 발송은 Outbox 소비자 범위로 분리하고 운영 화면에 개발 토큰을 노출하지 않는다.
- 화면·컨셉 HTML에 제작 도구·모델·프롬프트 메타데이터를 표시하지 않는다.

## 실행·성공 기준
1. Issue와 완료 조건을 만든다.
2. 005 migration으로 조직 유형, 초대 테이블, CHECK·UQ·FK 인덱스를 추가한다.
3. 조직 부모가 같은 법인인지, 팀 아래 하위를 만들지 않는지 Service에서 검사한다.
4. 관리자가 재인증 후 초대를 발급한다. 성공: DB에는 해시만 있고 개발 환경에서만 링크 재료 반환.
5. 익명 사용자가 CSRF와 비밀번호 정책을 통과해 수락한다. 성공: 사용자·역할 범위·감사·수락 시각이 한 트랜잭션에 저장.
6. 재사용·만료·취소·중복 이메일·다른 조직 연결을 4xx로 차단한다.
7. 관리자·활성화 UI, 컨셉 HTML, 설계·DB·체크리스트·보고서를 갱신한다.
8. 단위, Docker HTTP/DB, health, 유지보수, 백업·격리 복구, diff를 통과한 뒤 커밋·푸시한다.

## 종료·실패 기준
구문·단위·통합 실패, 원문 토큰 저장, 권한 우회, 3서비스 unhealthy, 복구 건수 불일치가 있으면 미완료다. 모든 자동 증적과 문서가 일치하면 종료한다.
