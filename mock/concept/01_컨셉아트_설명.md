# 화면 컨셉아트

## 방향

건설 현장의 신뢰·안전을 상징하는 네이비를 주색으로, 주의와 행동을 뜻하는 안전 오렌지를 CTA에 사용한다. 좌측 업무 메뉴, 상단 검색, 4개 KPI 카드, 비품 표, 대여/반납 현황을 기본 골격으로 한다.

## 판서 반영

- 로그인 후 대시보드 데이터 표시
- 비품 등록 및 재고 설정
- 대여/반납 연결
- 사용자/권한과 감사 로그
- 검색·필터·페이지형 목록
- 반응형 모바일 화면

생성 이미지: `mock/concept/seowon-inventory-concept.png`

## 생성 메타프롬프트

ROLE=기업용 UI 디자이너. GOAL=서원토건 비품관리의 데스크톱 대시보드 컨셉 제작. CONTEXT=좌측 메뉴, 상단 검색, 전체/대여/지연/부족 KPI, 비품표와 알림. STYLE=네이비·안전 오렌지·고대비·절제된 건설업 정체성. SUCCESS=한국어 핵심 라벨이 읽히며 실무 동선과 반응형 구조가 보임. AVOID=과도한 장식, 외부 로고, 워터마크.
